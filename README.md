# 📊 AW Sales — Power BI Sales Dashboard

## 📌 Project Overview

**AW Sales** is an interactive **Power BI sales analysis dashboard** built using the Adventure Works sales dataset.

The project transforms raw sales data into interactive visualizations and business insights. It demonstrates the use of **Power Query, data modeling, DAX, and Power BI visualizations** to analyze sales performance and support data-driven decision-making.

---

## 🎯 Business Objectives

The main objectives of this project are to:

* Analyze overall sales performance
* Monitor key sales KPIs
* Identify sales trends over time
* Evaluate product performance
* Analyze customer purchasing behavior
* Compare sales across different categories and regions
* Identify high-performing areas and potential opportunities
* Present business information through an interactive dashboard

---

## 📈 Key KPIs

The dashboard provides an overview of important sales performance metrics, such as:

* **Total Sales**
* **Total Orders**
* **Total Customers**
* **Total Products**

* **Sales Growth**

## 🚀 How to Use

1. Download **`AW Sales.pbix`** from this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open the `.pbix` file in Power BI Desktop.
4. Explore the dashboard pages.
5. Use the available slicers and filters to interact with the report.
